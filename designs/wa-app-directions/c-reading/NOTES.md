# C, "Reading, not chatting"

- **Axis:** the deliberate break. A chat is a readable transcript: no bubbles, sender name as a small label, own messages set apart by an indent and a left rule, voice notes as quoted text first with a small play control. List, chat structure and bottom tabs stay.
- **Finding answered:** F3 (transcripts first-class), F2 (the draft is a tinted full-width margin note with an accent rule, small-caps label, italic alternatives, "Use" and "Dismiss"; nothing in the transcript looks like it).
- **Motion idea:** almost still; opening a chat fades the lines in once, 14 ms apart, 100 ms each, about 260 ms total. Off under reduced motion.
- **Motif only this product has:** the transcript voice note, set as a hanging-quote paragraph in the reading column, with the audio demoted to a small play control beneath it. The draft as an editor's note.
- **Reference:** editorial sites such as jakov.xyz. Borrowed: serif body text (Newsreader) against Geist chrome, generous line-height, a ~720 px (about 70ch) centred measure in the desktop pane, near-empty warm backgrounds, ink-black on paper and off-white on warm black.
- **Accent:** ink red (dark #ee6a52, light #a8281b), used only for unread (time, badge) and drafts (draft card, "Drafts on" marks).
- **Fonts:** Newsreader (message text, names, draft) and Geist (chrome).
- **Notes:** the open chat "Ekipa za vikend" is not in the chat list data, so no row is highlighted on desktop. Composer and tabs are static at the end of the page so full-page screenshots read correctly; a real build pins them.
